# ChatGPT Pro充值教程｜100、200、500美元档位与国内付款

Plus频繁到用量上限时，可以比较Pro，但先看自己耗在哪类任务上。当前Pro已列有100、200、500美元三个月费档位。

## ChatGPT Pro现在有几个档位？

官方定价页当前列出 **100、200、500美元/月** 三个Pro价格档，500美元档提供相应的Ultrafast访问权益。具体模型、用量及其他功能要看账号和当前套餐说明。

| 套餐 | 官方月费 | 购买前的判断 |
| --- | --- | --- |
| Plus | 20美元 | 现有用量是否足以完成工作 |
| Pro 100美元档 | 100美元 | 升级后的权益是否解决实际瓶颈 |
| Pro 200美元档 | 200美元 | 更高用量是否有持续需求 |
| Pro 500美元档 | 500美元 | 是否确实需要该档的速度和用量权益 |

网页标价不等于最终含税金额，也不等于第三方人民币商品售价。

## 旧称Pro 5x、Pro 20x还能直接照着买吗？

部分文章和商家仍使用5x、20x区分100、200美元档位。**实际权益以当前账号内显示的套餐为准。** 下单时要核对对应的官方套餐和实际到账结果。

5x、20x不代表回答质量或智能水平提高相同倍数。不同任务和模型的消耗不同，准确额度和重置时间应查看当前账号用量页。

## 2026年10月，模型和订阅要怎么区分？

购买的是 ChatGPT 订阅，而不是某个模型的永久使用权。ChatGPT 的 Chat、Work 与 Codex 入口也不能混为一谈。

当前 Work/Codex 的模型包括 **GPT-6 Astra、GPT-6.1 Sol、GPT-6 Sol 和 GPT-6 Luna**；其中 GPT-6.1 Sol、GPT-6 Sol、GPT-6 Luna 不在 Chat 中提供。实际选项取决于套餐、客户端和开放进度。

如果主要用来写代码，可以先看 Plus 与 Codex 的关系，再决定是否付费升级。

## 什么时候值得从Plus升级？

先看一段时间的实际用量：是否经常等待重置、什么任务消耗最高、等待是否影响工作。偶尔到顶与每天运行长任务，对套餐的要求不同。

升级前比较当前额度、额外credits和Pro价格。额度与速度是不同指标，不能把最高价格理解成所有任务都无限、都最快。

## 官方开通步骤

1. 登录自己的ChatGPT账号，进入套餐设置。
2. 查看该账号当前可选的Pro档位和结算币种。
3. 已有Plus时，核对升级生效时间、差额和后续续费金额。
4. 用结账页实际支持的方式付款。
5. 回到账户订阅和用量页确认结果，保存收据。

## ChatGPT有哪些付款路径？

| 方式 | 需要核对什么 | 使用边界 |
| --- | --- | --- |
| 官网银行卡付款 | 账号地区、发卡地区、账单信息、银行授权 | 有 Visa/Mastercard 标识不代表一定能通过 |

支付成功还取决于产品的地区与账号要求，不能仅靠换卡或买礼品卡判断是否可用。官网没有显示某个钱包时，不应假设绑定海外卡后就一定会出现。

## 第三方卡密充值怎么操作？

没有适用的官方支付方式时，部分用户会考虑人民币卡密服务。文中保留的 [第三方充值入口](https://payai.plus/) 是独立服务，与 OpenAI、Anthropic 官方订阅入口不同。

1. 核对商品是个人订阅、共享账号还是其他服务，以及对应套餐和时长。
2. 确认当前人民币报价、付款方式、账号条件和失败退款规则后再下单。
3. 获取卡密后，先核对充值页面域名与授权要求，再按指引操作。
4. 完成后回到产品自己的订阅页面，检查套餐和有效期，保存订单记录。

**卡密是第三方交付凭证。** 购买前应了解授权方式，不向不可信页面提供密码、验证码、Cookie、Session Token 或 API Key。本次更新核对了公开资料，未重新完成第三方付款实测。

## 已有Plus或Pro，能否直接用卡密覆盖？

不要默认覆盖会顺延时间。第三方商品可能要求当前无有效订阅，或有单独的升级限制。先核对原订阅、目标档位、剩余时间和退款条件；不理解提示时不要提交。

- 不把“自助充值”理解成官方授权或零风险保证。
- 保存订单与实际到账记录；续费和退款要按原付款渠道处理。
